Демонстрация плавного появления футера

Прокрутите страницу вниз, чтобы увидеть, как футер плавно появляется при скролле.

Преимущества оптимизированного решения:

  • GPU ускорение - использование translate3d для аппаратного ускорения
  • CSS Custom Properties - минимальные изменения DOM
  • Passive listeners - не блокируют скролл
  • Оптимизированный throttling - правильное использование requestAnimationFrame
  • Easing функции - более естественная анимация

Современное решение (CSS Scroll-Driven Animations)

Для браузеров, поддерживающих новый стандарт CSS Scroll-Driven Animations, используется чисто CSS решение без JavaScript.
